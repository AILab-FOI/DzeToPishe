# DzeToPishe
Diplomski rad Zlatko Pračić

## Struktura repozitorija
| Struktura projekta | Opis |
|:---|:---|
| `/diplomski-rad/` | **Korijenski direktorij** |
| `├── data/` | Dokumenti i podaci za rad chatbota |
| `│   ├── raw/` | Izvorni dokumenti (DOC, PDF, HTML) |
| `│   └── pitanja.txt` | Datoteka s pitanjima |
| `├── notebooks/` | Sve verzije chatbota u .ipynb formatu |
| `│   ├── v1_vanilla.ipynb` | Prva, osnovna verzija |
| `│   ├── v2_rag.ipynb` | Verzija s RAG-om |
| `│   └── v3-fine-tune.ipynb` | Verzija s fine-tune |
| `├── src/` | (Opcionalno) .py skripte |
| `│   └── utils.py` | Pomoćne funkcije koje se ponavljaju |
| `├── .gitignore` | Datoteke koje GitHub treba ignorirati |
| `├── README.md` | Glavni opis projekta i upute |
| `└── requirements.txt` | Popis biblioteka za instalaciju |
